# Pain Atlas website deployment

[Open the website](https://amealf.github.io/body-pain-atlas-web/)

Generated website files for version 1.2.0. Start with a lightweight body diagram, choose a region such as Head, then explore its original Human Atlas structures and record pain type and intensity. Only the chosen region loads. The interface follows the browser language unless a language is selected explicitly. Pain records stay in each visitor's browser. Google sign-in and cloud storage remain deferred.

[Latest desktop and offline downloads](https://github.com/amealf/body-pain-atlas-web/releases/latest)
