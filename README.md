# Pain Atlas website deployment

[Open the website](https://amealf.github.io/body-pain-atlas-web/)

Generated website files for version 1.0.0. Use the original 3D body surface to choose a broad area, a specific location, and pain type and intensity. Pain records stay in each visitor's browser. Google sign-in and cloud storage are not enabled in this release.

[Download Windows, macOS and offline HTML](https://github.com/amealf/body-pain-atlas-web/releases/tag/v1.0.0)

Anatomy: [Human Atlas](https://github.com/ashemag/human-atlas), BodyParts3D (CC BY 4.0). See THIRD-PARTY-NOTICES.txt.
