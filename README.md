# Pain Atlas website deployment

[Open the website](https://amealf.github.io/body-pain-atlas-web/)

Generated website files for version 1.1.0. Use the complete Human Atlas model, system filters and the original exploded view to choose a broad area, a specific structure, and pain type and intensity. The model uses neutral colors. Pain records stay in each visitor's browser. Google sign-in and cloud storage are not enabled in this release.

[Download Windows, macOS and offline HTML](https://github.com/amealf/body-pain-atlas-web/releases/tag/v1.1.0)
